# 2階LDK フォトギャラリー

[GitHub Pagesでギャラリーを見る](https://dddedo921.github.io/home-planning-gallery/)

2階LDKの写真風イメージ14点を掲載しています。画像を選ぶと拡大でき、前後の視点に切り替えられます。俯瞰・階段には、壁や天井を一部外した検討用の表示を含みます。

[ダイニングチェア比較](https://dddedo921.github.io/home-planning-gallery/yama.html)では、7画角の写真風イメージで現行のYチェアとyama OAK エクリュ（板座）を見比べられます。
